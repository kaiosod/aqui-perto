# Project Name = Nearby (Aqui Perto)

Web application for locating nearby establishments and services, with a focus on simplicity, usability, and user experience (UX).

## 📌 Project Description

**Here Nearby** is a web application prototype that allows users to find nearby establishments — such as restaurants, pharmacies, and markets — based on their current location.

The main goal of this project is to demonstrate that a **simple and minimalist interface**, grounded in usability principles, can provide a clearer and more efficient user experience compared to feature-heavy solutions.

This project was developed as part of a **Final Course Project (TCC)** in the field of Software Engineering.

---

## 🎯 Features

- User location detection via browser geolocation
- Category selection for establishments
- Clean and objective listing of nearby places
- Minimalist and accessible interface
- Consumption of a public geolocation API (OpenStreetMap / Overpass API)

---

## 🛠️ Technologies Used

- **Frontend:**  
  - React  
  - TypeScript  
  - Vite  
  - Tailwind CSS  

- **APIs:**  
  - Overpass API (OpenStreetMap)

> The application does not use a dedicated backend. It consumes a public API directly, a design decision made to reduce architectural complexity and maintain focus on user experience.

## ▶️ Running the Project Locally

### Prerequisites
- Node.js (LTS version recommended)
- NPM

### Steps

```bash
# Clone the repository
git clone https://github.com/your-username/here-nearby.git

# Navigate to the project folder
cd here-nearby

# Install dependencies
npm install

# Start development server
npm run dev
npm run build 
npm run preview -- --host

# The application will be available at:

http://localhost:5173
```
